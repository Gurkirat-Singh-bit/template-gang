# Warehouse

Your personal collection of starter projects, components, and resources.

- `category/` contains your work, organized by technology.
- `web/` is the Next.js catalog. It discovers categories and items directly from those folders.

## Run

```sh
cd web
bun install
bun run dev
```

Open the address printed by Next.js. See [web/README.md](web/README.md) for adding resources and React previews.
