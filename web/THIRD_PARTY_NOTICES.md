# Third-party notices

The interface adapts VengeanceUI's MIT-licensed theme and button, input, tabs, copy-control, and documentation conventions. The Action button adapts its AnimatedButton using CSS animation. The select retains the upstream Radix architecture; input and dialog use native browser elements. No animation or form framework is installed.
